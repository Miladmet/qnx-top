Purpose-Built for QNX Microkernels

Traditional Unix tools can't see microkernel primitives. qnx-top bridges the gap.

🔀

REPLY-Blocked Client Tracking

Shows which threads are REPLY-blocked, on which server process and channel, and for how long. Priority inversion detection is not implemented.

🛡️

Adaptive Partitioning (APS)

Detects whether the APS scheduler is active on the target. Per-partition budgets are not read yet and are shown as N/A.

📂

/dev Listing and Telemetry Endpoint

Lists the entries under /dev (owner and handler details are shown as N/A) and serves a text report at /dev/qnx_top.

Microkernel Deep Diagnostics

Unmasking synchronous IPC bottlenecks that standard monolithic top tools cannot see.

⚡

MsgSend & MsgReceive Tracing

Maps client threads in STATE_REPLY directly to the target server process and channel ID (chid). Highlights stalls exceeding the 2.0 ms safety threshold.

🧩

Native Resource Manager

Registers /dev/qnx_top as a standard POSIX I/O device. Read diagnostic snapshots anytime with cat /dev/qnx_top via a dedicated dispatch thread.

🧪

Turnkey Stall Reproducer

Includes qnx-stall-demo, a test utility to inject controlled server latency into real QNX channels and verify observability pipelines under load.

Quickstart & Build Instructions

Built with standard C11 and CMake for QNX Neutrino 8.0 SDP and host compatibility.

1. Target Build (QNX SDP 8.0)

Cross-compile with the official QNX toolchain.

source /opt/qnx800/qnxsdp-env.sh
cmake -B build -DCMAKE_TOOLCHAIN_FILE=cmake/qnx800-x86_64.toolchain.cmake
cmake --build build
  • Targets QNX Neutrino 8.0 x86_64 & aarch64
  • Native procfs & devctl telemetry
Testing

2. Host Mode & CI Suites

Verify algorithms, snapshot invariants & concurrency.

cmake -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
  • Comprehensive state mapping unit tests
  • LLVM ThreadSanitizer verified

3. Run & Observe Stalls

Launch profiler with live thread inspection.

# Terminal 1: Inject simulated IPC latency
./qnx-stall-demo -d 50

# Terminal 2: Inspect blocked threads
./qnx-top -t
  • Thread view with server channel attribution
  • Instant cat /dev/qnx_top snapshot
